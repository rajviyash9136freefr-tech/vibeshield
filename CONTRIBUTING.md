# Contributing to VibeShield 🛡️

First off, thank you for considering contributing to VibeShield! Whether you're reporting a bug found during vibe coding, adding rules for hallucinated packages, or improving agent skills, you are warmly welcome here.

---

## 🌟 How You Can Contribute

1. **Add Bug Hunter Rules**:
   - VibeShield rules live in the [`rules/`](rules/) directory in simple YAML format.
   - Found an LLM hallucinating a non-existent package or scaffolding dangerous boilerplate? Submit a YAML rule with golden test fixtures.

2. **Improve AI Agent Integrations**:
   - Help enhance prompts and integrations for Cursor, Claude Code, Windsurf, Copilot, or Aider in [`skill/`](skill/) and [`site/src/data/site.ts`](site/src/data/site.ts).

3. **Report AI Coding Bugs & False Positives**:
   - [Open an Issue](https://github.com/rajviyash9136freefr-tech/vibeshield/issues) with the code sample generated by your AI agent and the unexpected behavior.

4. **Enhance the Web Simulator & Documentation**:
   - The documentation and interactive simulator live in [`site/`](site/) built with Astro 5 and Tailwind CSS v4.

---

## 💻 Local Development

### Scanner Engine (Go)
```bash
cd scanner
go test ./...
go build -o vibeshield cmd/vibeshield/main.go
```

### Documentation & Website (Astro)
```bash
cd site
npm install
npm run dev
```
