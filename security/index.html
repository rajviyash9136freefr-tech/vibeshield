Trust

Security & threat model

What leaves your machine

  • Nothing, on every surface. The CLI, the console, the pre-commit hook and the GitHub Action all run the same static analysis from the pack embedded in the binary. There is no telemetry, no account, no upload, and no server component to send anything to.
  • There is no VibeShield cloud. The --online flag is reserved for a future package-intel lookup; in this build it prints a notice and the scan continues fully offline. The scanner contains no HTTP client at all.
  • The Action runs on your runner. It posts a PR comment using your GITHUB_TOKEN. The only thing that leaves the runner is that comment, in your repository.
  • Nothing is ever used for model training. There is no model, and nothing to train it with.

Trust boundaries

How the scanner reads your code

  • Read-only file access; the scanner never writes to your repo (init writes config files, and says so first).
  • It does not execute your code, install dependencies, or build. Findings are pattern matches over text, weighted by AI-likelihood.
  • Secrets found in matched lines are redacted by the scanner (4 + 4 characters kept) before anything is printed, posted, or sent.
  • Rule packs are data, not code. A malformed pack is a startup error (exit 2), never something that gets evaluated.

Disclosure

Found a vulnerability in VibeShield itself? Open a private report through GitHub Security Advisories — that keeps the details private until there is a fix. We acknowledge within 48 hours and aim to ship a fix within 14 days for anything rated high or above. Please don't open a public issue first; we'll credit reporters who give us the window. The full policy is in SECURITY.md.

Precision, honestly stated

No scanner is right all the time. Our release bar is ≥ 85 % precision on critical/high findings against a 200-PR golden set, ≤ 5 false positives per 1k diff lines, and every dismiss carries a required reason into an audit log we can learn from. When a rule underperforms we lower its confidence or retire it — the pack's changelog is public in the repo.
