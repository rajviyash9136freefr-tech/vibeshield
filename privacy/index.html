Privacy

Last updated September 13, 2026 · VibeShield is MIT-licensed open source — this document explains the license, not a product you buy.

plain-language note — The scanner is the product, and the scanner runs on your machine. The only network traffic this project generates is one you opt into (--online) or one that posts findings to your own pull request. Everything below is an expansion of that sentence, not an exception to it.

1.Your code

The CLI, the console and the pre-commit hook perform static analysis entirely on your machine and send nothing anywhere. The rules engine runs from the pack embedded in the binary; there is no "phone home" call to disable because there is no call — the scanner links in no HTTP client at all.

The --online flag is reserved for a future package-intel lookup and does nothing in this build: it prints a notice and the scan continues fully offline. When it lands, it will send package names from your manifests to public registries to score slopsquatting risk — names out, file contents never — and it will stay opt-in.

In GitHub Action mode, analysis runs on your GitHub runner. What leaves the runner is the VibeCheck report: findings — file paths, rule IDs, symbol names, severities — posted as a comment on your own pull request using your own GITHUB_TOKEN. Secrets that match a pattern are redacted to four characters on each side before anything is printed or posted. There is no VibeShield server for that report to reach.

2.This website

No advertising cookies, no third-party trackers, no fingerprinting. Fonts are self-hosted, so a page view leaks nothing to Google.

The site is a GitHub Pages static build. It cannot see your code because your code is never sent to it.

3.Accounts

There is no VibeShield account to have — the tool is MIT-licensed, free, and runs without signup, a key, or a seat. There is no dashboard, no cloud API and no GitHub OAuth flow, because there is no server component. Nothing about you is stored anywhere, because there is nowhere to store it.

4.What we never collect

A short list, because it is the point:

  • Your source code or file contents, in any mode.
  • Your package names — no lookup is performed in this build.
  • Your repository names, branch names, or finding history.
  • Keystrokes, editor telemetry, or anything resembling an IDE agent.
  • Personal profiles, cross-site identifiers, or contact lists for marketing.

5.Changes to this page

If the promise on this page ever changes, it is a product change worth an announcement, not a legal footnote worth a diff. The honest summary: we would rather tell you than update this quietly — and a security tool that does not keep its privacy promises does not deserve to run on your repos.

6.Contact

Privacy questions go to GitHub issues — the scanner is one repo, the whole network surface is one grep away, and the answer is usually "there isn't any".

Questions about this document? Open an issue on GitHub — there is no support mailbox, and the repository is where this project actually lives.
