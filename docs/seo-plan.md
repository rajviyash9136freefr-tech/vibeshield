## 1. Strategy Overview & Core Rules
- **No Meta Keywords:** The deprecated `<meta name="keywords">` tag is intentionally omitted.
- **Natural Integration:** Keywords are incorporated naturally into `<title>`, `<meta name="description">`, `<h1>`, `<h2>`, image `alt` attributes, canonical URL slugs, anchor text, and JSON-LD schema graphs.
- **Strict Truth-in-Advertising:** Keywords focus exclusively on actual capabilities verified in the codebase (static analysis, hallucinated package detection / slopsquatting, secret detection, insecure framework defaults, pre-commit hooks, and zero network egress).
- **Target Specifications:**
  - `<title>`: 50–60 characters, brand suffix `— VibeShield`
  - `<meta name="description">`: 140–160 characters, concise and action-oriented
