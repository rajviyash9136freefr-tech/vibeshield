Core Capabilities

Built Specifically for AI-Generated Code

Traditional SAST and SCA tools look for yesterday's CVEs. VibeShield hunts the new class of bugs unique to AI coding agents and LLMs.

📦 SLOPSQUATTING DEFENSE

Hallucinated Package Blocker

LLMs routinely invent plausible package names. Attackers register these hallucinated names on npm and PyPI within hours. VibeShield checks package age, maintainer count, and registry existence before installation.

🔑 ENTROPY SCANNER

Zero-Leak Secret Quarantine

Catches OpenAI, Anthropic, AWS, GitHub, and database credentials echoed by coding agents into source files or test fixtures. Generates immediate rotation warnings before git commit.

🛡️ SCAFFOLD SANITIZER

Insecure Boilerplate Blocker

Refuses unsafe AI scaffolding defaults: wildcard CORS (*), unhashed passwords, disabled TLS verification, JWT alg "none", and eval() executed directly on model outputs.

⚡ AIR-GAPPED PERFORMANCE

Sub-Second Local Execution

Written in high-performance native code. Runs in under 400ms across your local git diff. 100% offline, zero cloud calls, zero telemetry — your intellectual property never leaves your laptop.

Install VibeShield in Under 60 Seconds

Install the offline binary for Windows, macOS, or Linux, add it as a git pre-commit hook, or enforce it in CI via our official GitHub Action. 

# macOS & Linux (Bash):
curl -fsSL https://raw.githubusercontent.com/rajviyash9136freefr-tech/vibeshield/main/scripts/install.sh | bash

# Windows (PowerShell):
irm https://raw.githubusercontent.com/rajviyash9136freefr-tech/vibeshield/main/scripts/install.ps1 | iex

# Then confirm it is wired up:
vibeshield doctor
# Claude Code:
claude plugin marketplace add rajviyash9136freefr-tech/vibeshield
claude plugin install vibeshield@vibeshield

# Automatic via install script, or copy .cursorrules from the Agent Prompts section above!
# Instant scan without installation:
npx vibeshield scan .

# Or install globally via npm:
npm install -g vibeshield

# Tab completion, once installed:
vibeshield completion bash >> ~/.bashrc
# .github/workflows/vibeshield.yml
name: VibeShield PR Gate
on: [pull_request]
jobs:
  audit:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: rajviyash9136freefr-tech/vibeshield/action@v3.0.0

How to Scan & Fix Insecure AI Code

Run instant local audits from your terminal or inside your agent. Copy any command below to test your workspace immediately.

1. Scan Entire Project

Full Audit

Audit all repository files, dependency manifests, and components for hallucinated packages, leaked keys, and insecure code. 

vibeshield scan .

2. Scan Git Diff Against Main

PR Speed

Audit only the changed files from your current AI coding session before opening a pull request. 

vibeshield scan --diff main

3. Scan Staged Files (Pre-Commit)

Fast Hook

Sub-second check before git commit. Blocks secrets and hallucinated imports before they enter git history. 

vibeshield scan --staged

4. Automatically Apply 1-Line Fixes

Auto-Remediate

Interactively preview and auto-remediate flagged hallucinated packages with verified standard library replacements. 

vibeshield fix .

Frequently Asked Questions

01

What is VibeShield and how does it test vibe-coded apps?

VibeShield is an adversarial bug hunter and security tester built specifically for AI vibe coding. When AI agents (Cursor, Claude Code, GitHub Copilot, Windsurf) generate hundreds of lines of code, they introduce hallucinated packages, leaked keys, and broken component logic. VibeShield inspects code the moment it is written, hunts these specific bugs, and gives you instant 1-click fixes before you commit or merge.

02

How do I install VibeShield and use it with my AI coding agent?

Four ways, one binary. (1) Run the install script on macOS/Linux or the PowerShell installer on Windows. (2) Copy our agent prompt into .cursorrules, .windsurfrules or the Claude Code plugin. (3) Add the GitHub Action to gate every pull request in seconds. (4) npx vibeshield scan . for a zero-install scan. Then run vibeshield doctor to confirm everything is wired up.

03

What specific bugs and vulnerabilities does VibeShield hunt down?

VibeShield targets failure modes unique to LLM-generated code: hallucinated npm/pip packages (slopsquatting attacks where attackers pre-register names invented by LLMs), leaked API keys and passwords echoed in boilerplate, insecure wildcard CORS (*), broken JWT auth, stripped licence headers, and prompt-injection backdoors. 122 rules across 6 categories — all readable with vibeshield rules.

04

Does my source code or prompt data leave my machine?

No. Never. VibeShield is designed for zero data exfiltration. The CLI, console, pre-commit hook, GitHub Action and agent skill all execute 100% locally using static analysis. There is no telemetry, no account, no dashboard, and no server component — the scanner links in no HTTP client at all. Your code, API keys, and prompts are never sent anywhere.
